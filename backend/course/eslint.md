# Es lint
Es lint is a program that constantly scans our code and finds potential coding erros or simply bad coding practise.
It can also be used as code formatter.

in `.eslintrc.json` we can configure different rules that we can enforce in our code.

popular eslint convention is eslint-config-airbnb: 
In order to setup that we have to install several packages which airbnb config depeds on,
- eslint
- eslint-config-airbnb
- eslint-config-prettier
- eslint-plugin-import
- eslint-plugin-jsx-a11y
- eslint-plugin-node
- eslint-plugin-prettier
- eslint-plugin-react

`npm i {everthing_up_there} --save-dev`


It's very important to have code linting in a project.
