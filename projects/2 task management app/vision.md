# Task Management App (often called a To-Do list on steroids).


1. Authentication : Login/signup
2. Dashboard: Smart lists with filter (today, week ,month, year, all tasks, overdue)
 - quick add to add quick task in the dashboard
3. Task management : Create/ Edit Task
- Fields: Title (String, required), Description (Textarea), Due Date (Date), Priority (Low/Medium/High), Status (To-Do / In-Progress / Done), Assigned To (if you allow multiple users later).
- NEW Concept: Sub-tasks (Checklist inside a task).
4. Task List/Board: List View: Table with sortable columns (Sort by Due Date, Priority).
- Board View (Kanban): 3 columns (To-Do, In-Progress, Done). Drag and drop tasks between columns (This updates the status field).
5. . Analytics (1 Page - Lighter than Day 1)
    Productivity Score: Total tasks completed today vs. total tasks due today (percentage).
    Bar Chart: Tasks completed per day for the last 7 days.
6. Profile / Settings (1 Page)

    Update Name/Password.

    NEW: Set default notification preferences (e.g., "Email me daily reminders at 8 AM").



### The Market & Competitors (What to copy)

    - Trello / Jira: Best for Board view (Drag and drop columns: To-Do, Doing, Done).
    - Todoist: Best for natural language processing (Type: "Submit report tomorrow at 5pm" and it auto-fills the date).
    - Notion / Asana: Best for sub-tasks and dependencies.
    - Microsoft To Do: Best for My Day (daily focus planning):
